## 为什么国内访问海外，线路比配置更重要

先说一个基本事实：同一台服务器，用普通线路 ping 可能 200ms 往上、晚高峰丢包 10% 以上，换成 CN2 GIA 优化线路后延迟可以压到 150ms 左右、丢包几乎为零。差距不在机器本身，而在数据回国的路径。

国内访问海外 VPS 的常见线路有这几类：

- **普通国际线路**：走公网路由，路由节点多，晚高峰国际出口拥堵时速度明显下降。
- **CN2 GT**：中国电信的全球传输业务，去程回国时才走 CN2 网络，路由不够彻底，晚高峰仍可能绕路拥堵。

- **AS10099 / CMIN2**：分别对应联通和移动的精品直连网络，配合电信 CN2 GIA 就是我们常说的“三网直连”。
